# Checklist de Capturas (Portfolio)

Para maximizar el impacto del README, toma **5 capturas clave** y guárdalas en esta carpeta con estos nombres exactos:

## 📸 Capturas necesarias

### 1. `login.png`

- Pantalla de inicio de sesión.
- Muestra formulario + opción "¿Olvidaste tu contraseña?".
- Captura en modo claro (light theme).

### 2. `dashboard.png`

- Dashboard principal con selector de empresa.
- Muestra las 3 empresas disponibles (MAMEN, DRDL, WINICAR).
- Nota: no selecciones ninguna, deja el placeholder visible.

### 3. `invoice-form.png`

- Formulario de factura completo con datos de ejemplo.
- Vista de una plantilla completada lista para exportar.
- Incluye campos rellenos y botón de "Generar PDF".

### 4. `admin-users.png`

- Panel admin, tab "Usuarios".
- Tabla con lista de usuarios (mínimo 2-3 filas de ejemplo).
- Muestra botones de acción (editar, eliminar).

### 5. `admin-password-reset.png`

- Panel admin, tab "Solicitudes de Reset".
- Lista con al menos 1 solicitud pendiente.
- Muestra los botones de aprobar/rechazar.

---

## 🎨 Tips de captura

- Usa resolución 1920x1080 o mayor.
- Captura ventana completa (no recortes header).
- Modo light theme para mejor contraste en README.
- Si usas herramientas:
  - Windows: `Win + Shift + S`
  - macOS: `Cmd + Shift + 4`
  - Extensión: Awesome Screenshot (Chrome/Edge)
